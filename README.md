# AI Chatbot 🤖

AI Chatbot developed using Python Flask.

## Features

✔ Modern UI

✔ Dark Mode

✔ Typing Animation

✔ Date Support

✔ Time Support

✔ Predefined Responses

✔ Responsive Design

## Tech Stack

- Python
- Flask
- HTML
- CSS
- JavaScript

## Installation

```bash
pip install flask
python app.py
```

Open:

http://127.0.0.1:5000
